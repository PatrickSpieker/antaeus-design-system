# Fonts

Antaeus Health currently uses **Google Fonts** for all typefaces.

## Current stack

| Role    | Family              | Source        | Status    |
|---------|---------------------|---------------|-----------|
| Display | Faustina            | Google Fonts  | ✅ Active |
| UI/Body | IBM Plex Sans       | Google Fonts  | ✅ Active |
| Mono    | JetBrains Mono      | Google Fonts  | ✅ Active |

Loaded via `@import` at the top of `colors_and_type.css`.

## Substitutions & upgrades

If the brand wants to move to licensed typefaces, the aesthetic targets are:

- **Display** → Faustina stands in for *Tiempos Text* (Klim) or *Freight Text* (Darden). Humanist, warm, slightly flared — reads consumer without losing seriousness. Use 500 at display sizes, 400 for long-form.
- **UI/Body** → IBM Plex Sans is a deliberate choice, not a substitute: humanist skeleton echoes Faustina, and it carries institutional credibility (IBM commissioned it as their corporate face). Keep it unless the brand moves away from that register.
- **Mono** → JetBrains Mono stands in for *Söhne Mono* or *Berkeley Mono*.

**🚩 Flag for the user:** We have not licensed any paid typefaces. If you want to upgrade to Söhne + Tiempos (the "serious consumer product" stack — used by Stripe, Linear, Arc), please provide the font files and I'll swap them in.
