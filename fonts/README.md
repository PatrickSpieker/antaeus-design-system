# Fonts

| Role | Family | Token |
|---|---|---|
| Headings and eyebrows | IBM Plex Sans | `--font-heading` |
| Body and controls | Inter | `--font-body` |
| Metrics | IBM Plex Mono | `--font-mono` |

Loaded from Google Fonts by `colors_and_type.css`. Use role tokens in components. `--font-sans` aliases the body role for existing consumers. No serif font is loaded or supported.

Display headings use 1.15 leading. Body defaults to 15px / 1.55. Metrics use tabular numerals; identity phone numbers use Inter.
