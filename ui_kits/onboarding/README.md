# Onboarding references

Eight static screens adapted from [Devin’s addon at eed0918](https://github.com/devin-griser/antaeus-design-addon/tree/eed0918), using the agreed design-system tokens. Open `index.html` through the local preview server.

The frames model a 402 × 874 iPhone with 59px top and 34px bottom safe areas. These are mock-device constants, not production safe-area values. Controls illustrate states; signup, institution selection, and account actions are not connected. Complete keyboard interaction and error/loading states in the consuming application.
